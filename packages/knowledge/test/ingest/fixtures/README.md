# Official HTML fixture

`oegk-contact.html.txt` is the public ÖGK contact page downloaded on
2026-11-05 from:
https://www.oegk.at/cdscontent/?contentid=10007.878901&portal=oegkportal

The origin returned 404 for robots.txt (no published restrictions). This is
administrative contact information, not medical guidance. The Markdown snapshot
is generated by Vitest from this saved page. The live acceptance test fetches this
same seed once and searches the verbatim Standortsuche sentence.

Provider keys, site-verification tokens, session IDs and analytics IDs are
replaced with `REDACTED`. Surrounding markup, including scripts, is preserved so
normalization still exercises removal of source-site scripts and navigation.
Check saved fixtures with `gitleaks dir --redact packages/knowledge` before adding
them; the fixture regression test also checks these redacted fields.
